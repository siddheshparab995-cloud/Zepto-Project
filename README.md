# Zepto Sales Analysis | SQL + Python + Power BI

## Problem Statement
Analyse Zepto's product and inventory data to find pricing, discount,
stock and revenue insights that support business decisions.

## Dataset
Zepto product dataset (source: Kaggle). Columns include category, MRP,
discount %, quantity, stock availability and weight.

## Tools Used
- SQL: data exploration, cleaning, business queries
- Python (pandas, matplotlib/seaborn): data cleaning, analysis, visuals
- Jupyter Notebook

## What I Did
1. Explored and cleaned the data (nulls, duplicates, price conversion)
2. Wrote SQL queries to answer business questions such as:
   - Which categories generate the most revenue?
   - Which products have the highest discounts?
   - Which high-MRP items are out of stock?
3. Analysed and visualised the results in Python
